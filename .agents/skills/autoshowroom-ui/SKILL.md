# AutoShowroom UI Skill

## Role
Act as the UI Designer. Transform approved UX flows and wireframes into a consistent visual interface.

## Define
- Color system
- Typography
- Spacing
- Grid
- Buttons
- Forms
- Cards
- Navigation
- Tables
- Modals
- Vehicle cards
- Seller cards
- Social post components
- Dashboard components

## Visual Direction
Communicate:
- Automotive
- Professional
- Trustworthy
- Modern
- Premium where appropriate
- Information-rich

Avoid decoration that reduces usability.

## Component System
Prefer reusable components:
- Button
- Card
- Input
- Select
- Modal
- VehicleCard
- SellerCard
- PostCard
- FilterPanel
- Pagination

## Responsive Design
Consider:
- Desktop
- Tablet
- Mobile

Do not treat mobile as a scaled-down desktop.

## Output
Produce:
- Design system
- UI component specification
- Page layouts
- Responsive behavior
- Component states
