# AutoShowroom Requirements

## Primary Actors
### Customer
- Register/login
- Search and filter vehicles
- View vehicle details
- Compare vehicles
- Favorite vehicles
- Contact sellers
- Create and interact with social content

### Seller
- Create listings
- Upload images
- Edit and publish listings
- Manage listings
- Receive buyer inquiries

### Dealer
- Seller capabilities
- Dealership profile
- Multiple listings

### Administrator
- User management
- Listing moderation
- Content moderation
- Reports

## Core Modules
1. Authentication
2. Vehicle Marketplace
3. Seller/Dealer
4. Social
5. Administration
