# AutoShowroom Agent Skills

Skill set for building the AutoShowroom automotive commerce and social platform.

## Development lifecycle

PO -> BA -> UX -> UI -> Architecture -> Development -> QA -> DevOps

Each skill defines:
- Role
- Responsibilities
- Inputs
- Process
- Outputs
- Rules
- Completion criteria

## Usage

Copy `.agents/skills/` into the AutoShowroom project root used by Codex.

Start with the lifecycle skills:
1. autoshowroom-po
2. autoshowroom-ba
3. autoshowroom-ux
4. autoshowroom-ui
5. autoshowroom-architecture
6. autoshowroom-development
7. autoshowroom-qa
8. autoshowroom-devops

The `references/` files are project-specific context and should be filled in with the team's actual framework, database, API conventions, design decisions, and requirements.
